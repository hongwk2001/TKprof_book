## REVISE (2)

- **P0006 n=3** — 今稷山 (Jiksan) is misread as "익산" (Iksan) — two different places;
  the audit's own fix keeps "Iksan." Fix: "익산" → "직산" / "Iksan" → "Jiksan" (Wirye's
  modern location, per the hanmun's own parenthetical).
- **P0013 n=5** — this quote has Seodong say he dug up "무" (radishes), but this
  chapter's own established backstory (P0011, already reviewed) is that he dug up 薯蕷
  — **yams** — and his very name 薯童 ("Yam-boy") depends on it. Internal
  inconsistency within the same story. Fix: KO "무를 캐는 땅" → "마를 캐던 땅," EN
  "radishes" → "yams."

## REJECT (3)

- **P0008 n4** — fix is identical to current text ("So Jeongbang," already matching this
  name's established spelling throughout the corpus); no real issue.
- **P0009 n1** — 浮山 is a distinct local mountain name (different hanja from the modern
  city 釜山/Busan); the note raises a fair disambiguation concern but the fix doesn't
  actually change anything, so there's nothing to apply.
- **P0011 n3** — 善花 and 善化 are genuinely different hanja but identical Korean
  pronunciation ("Seonhwa" either way) — this can't be distinguished in romanized
  English without exposing hanja, which the house style forbids. Current rendering
  ("Seonhwa (in another version, Seonhwa)") is about as good as it can get.
- **P0013 n2** — 一斗 does correspond to 말 (mal) in the traditional Korean unit system —
  unlike the 三升/되 mixup seen in an earlier chapter, this one is already correct. The
  note appears to be confusing this with that different, unrelated error elsewhere.
