# ch_02 — Claude review (2 equivalence + 18 quality = 20 items)

## ACCEPT (9)

- **P0003 n2** (equiv/EXTRA + quality/TERM_ERROR, same tag) — combined fix: (a) drop the
  added summary sentence "These were names referring to different ethnicities" (not in
  hanmun, violates the no-added-commentary rule); (b) 穢貊 was transliterated "해로/Haero"
  which matches neither reading of either character — should be "예맥/Yemaek", the
  standard ethnonym for these exact hanja. KO: "...말갈, 단국, 여진, 예맥으로 나뉜다."
  (drop trailing sentence). EN: "...Yeojin, and Yemaek." (drop trailing sentence).
- **P0010 n1** — 夫人 is the title "Lady," not literally "wife." fix_en correct.
- **P0014 n2** — minor phrasing, fix_en fine.
- **P0016 n1, n2, n4** — 靺鞨 rendered as modern "Manju/Manchu" (a ~17th-c. ethnonym) is a
  real anachronism for this text's frame. **But** REVISE the target: the fix proposes
  "Mohe," which is the standard sinological name but is NOT how this book renders 靺鞨
  everywhere else — the rest of this same chapter (P0002, P0009, P0017, P0018) already
  uses "말갈/Malgal" (the Korean-reading convention this whole translation follows, same
  as 樂浪→Nakrang not Lelang). Use "말갈/Malgal" at these 3 spots instead, for internal
  consistency, not "모허/Mohe."
- **P0017 n1** — 鴨淥 doesn't carry 城 in the hanmun; "Amnokseong" added a suffix. Fix to
  "Amnok" is correct.
- **P0017 n3** — 倭 in this pre-modern context is "Wa," not the anachronistic "Japanese."
- **P0022 n2** — 金官 → "Geumgwan," not "Geungwan" (dropped letter). Mechanical fix.

## REVISE (5) — real issue, model's fix wrong or incomplete

- **P0002 n2** — 大祖 here is 太祖 (Taejo, i.e. Wang Geon — Gyeon Hwon's real 930 letter
  was addressed to him), not a generic "Great Ancestor" as the fix renders it. This book
  already uses "태조/Taejo" as a specific figure elsewhere in this same chapter (P0022).
  KO: "견훤이 태조에게 글을 올렸다." EN: "Gyeonhwon submitted a letter to Taejo."
- **P0005 n1** — larger than flagged: KO drops the citation title 前漢書 (Book of the
  *Former* Han) entirely, and EN gets it backwards as "Book of the *Later* Han" — neither
  audit pass caught this, only found while reading the same paragraph for the flagged
  awkwardness. KO also garbles 始元 (the Shiyuan era name) into 원년 ("first year"),
  producing the nonsensical "first year's fifth year." Fix — KO: "《전한서》. 한나라 소제
  시원 다섯째 해인 기해년에 외부 두 곳을 설치했다..." EN: "The Book of the Former Han
  [records]: in the fifth year of the Shiyuan era of Emperor Zhao, the year Gihae, two
  outer commanderies were established..." (rest of paragraph unchanged).
- **P0009 n3** — flagged phrasing fix is fine, but misses a bigger one in the same
  sentence: 光虎帝 is the same naming-taboo substitution already documented in this book's
  own glossary for 周虎王 (虎 substituted for 武 to avoid Goryeo King Hyejong's name) — so
  光虎帝 = 光武帝, Emperor Guangwu, not a distinct "Gwanghoje." KO "광호제"→"광무제", EN
  "Gwanghoje"→"Emperor Guangwu" (plus apply the accepted phrasing fix).
- **P0012 n1** — 投于羅 = "surrendered to Silla" (羅 is this text's own standing shorthand
  for Silla, used elsewhere in the same chapter, e.g. "羅第六祇麻王"). The fix invents a
  nonexistent "kingdom of Ro." KO "로로" (itself a garbled double-syllable) → "신라"; EN →
  "surrendered to Silla."
- **P0018 n2** — flagged issue was just a romanization nit on "Daeryungsae," but the
  Korean reading itself is wrong at the character level: 柵 reads 책 (chaek), not 새 (sae,
  which is 塞) — KO "대령새" misread the character. Fix: KO "대령새"→"대령책", EN →
  "Daeryeongchaek" (or "the Daeryeong stockade").
